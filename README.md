# Smart Energy Meter Interface with GSM

## Project Overview
This project implements a Smart Energy Meter Interface using Arduino and GSM communication technology for remote electricity monitoring and billing applications.

## Features
- Energy consumption monitoring
- GSM-based SMS transmission
- Current sensor interfacing
- LCD display output
- Automatic billing calculation
- Embedded system implementation

## Hardware Components
- Arduino UNO
- GSM Module (SIM800L / SIM900A)
- ACS712 Current Sensor
- 16x2 LCD Display
- Jumper Wires
- Power Supply

## Software Used
- Arduino IDE
- Embedded C++
- GSM AT Commands

## Working Principle
The current sensor measures electricity usage and sends analog data to Arduino. Arduino calculates power and energy consumption, estimates the bill, displays the data on LCD, and transmits usage details via GSM module.

## Formula Used

Energy (kWh) = Power (kW) × Time (h)
